## 🛠️ Come Usare Questo Repository

### Opzione 1: Clona il repository in locale (Consigliato)
Se vuoi eseguire i notebook sul tuo computer e sperimentare direttamente con il codice:

```bash
# 1. Clona il repository
git clone [https://github.com/lucasimo2609-stack/youtube-code.git](https://github.com/lucasimo2609-stack/youtube-code.git)

# 2. Entra nella cartella del repository
cd youtube-code

# 3. Entra nella cartella dello specifico progetto (es. Video 02)
cd 02_decision_trees_rf_xgboost

# 4. Crea ed attiva un ambiente virtuale (opzionale ma consigliato)
python -m venv venv
# Su Windows:
venv\Scripts\activate
# Su macOS/Linux:
source venv/bin/activate

# 5. Installa le librerie necessarie
pip install -r requirements.txt

# 6. Avvia Jupyter Notebook
jupyter notebook
